# ftqc_faults

Use `ftqc_faults audit` to trace physical faults through a scheduled Clifford circuit. Use `ftqc_faults zx` to synthesize circuits, check fault equivalence or derive a stochastic gadget contract. The `steane` command runs both engines on the five-ancilla syndrome extractor and checks their physical fault responses against each other. [Guide and replay commands](GUIDE.md)
